# RotateFix

선택한 Android 앱이 전면에 표시될 때 화면 방향을 세로로 요청하는 로컬 도구입니다.

## 주요 기능

- 설치된 실행 앱 목록 표시
- 앱 이름 또는 패키지 이름 검색
- 여러 앱 선택 및 선택값 영구 저장
- 선택 앱 진입 시 세로 방향 적용
- 선택 앱 종료 시 기존 자동 회전 및 잠금 방향 복원
- 인터넷 권한과 서버 통신 없음

## 설치 및 설정

1. `RotateFix-v1.0.1-debug.apk`를 Android 8.0 이상 기기에 설치합니다.
2. RotateFix를 열고 `설정 변경 허용`을 누릅니다.
3. `시스템 설정 변경 허용`을 켭니다. 이 권한은 기존 회전 상태를 복원할 때만 사용합니다.
4. 앱으로 돌아와 `켜는 방법`을 누른 다음 `접근성 설정 열기`를 누릅니다.
5. 접근성 화면에서 `설치된 앱` → `RotateFix 세로 고정` → `사용`을 차례로 누르고 허용합니다. 이 서비스는 현재 전면 앱의 패키지만 확인합니다.
6. 목록에서 세로로 고정할 앱을 검색하고 체크합니다.

접근성 서비스를 강제 종료하거나 앱을 강제 중지하면 Android가 서비스를 해제할 수 있습니다. 이 경우 RotateFix의 `켜는 방법`에서 같은 순서로 다시 켜야 합니다.

## 호환성

RotateFix는 접근성 오버레이의 표준 방향 요청을 사용합니다. 일부 제조사 펌웨어, 게임, 카메라, 멀티윈도우 및 대화면 호환성 정책은 앱의 방향 요청을 무시할 수 있습니다.

## 빌드

Android SDK 경로를 `local.properties`의 `sdk.dir`에 지정하고 JDK 17을 준비한 뒤 실행합니다.

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

또는 Windows에서 `build-apk.cmd`를 실행하면 테스트와 린트를 거쳐 루트 폴더에 버전이 포함된 APK를 생성합니다.
