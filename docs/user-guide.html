RotateFix · 앱별 세로 고정

01

어떤 일을 하나요?

대상 선택

설치된 실행 앱을 이름·패키지로 검색하고 여러 앱을 선택합니다.

자동 세로 요청

접근성 서비스가 전면 앱을 확인해 선택한 앱에 세로 방향을 요청합니다.

원래 상태 복원

대상 앱을 벗어나면 기존 자동 회전과 잠금 방향을 복원합니다.

로컬 동작

인터넷 권한·서버 통신 없이 선택 목록을 기기에 보관합니다.

02

처음 사용하기

  1. APK를 설치하고 RotateFix를 엽니다.
  2. 설정 변경 허용에서 시스템 설정 변경 권한을 허용합니다. 기존 회전 상태 복원에 사용합니다.
  3. 켜는 방법 → 접근성 설정 열기에서 RotateFix 세로 고정 서비스를 직접 활성화합니다.
  4. 앱으로 돌아와 세로로 사용할 앱을 검색하고 체크합니다.
  5. 대상 앱 진입과 종료를 각각 시험해 방향 적용·원래 상태 복원을 확인합니다.
03

자주 쓰는 기능

대상 추가·해제
목록에서 앱을 체크하거나 해제합니다. 선택값은 재실행 후에도 유지됩니다.
서비스 복구
강제 중지나 시스템에 의해 서비스가 해제되면 켜는 방법에서 접근성 서비스를 다시 켜야 합니다.
범위 확인
현재 전면 패키지를 확인하는 서비스입니다. 모든 앱 화면·텍스트를 수집하는 사용법이 아닙니다.
04

문제가 생겼을 때

회전이 그대로입니다
접근성 서비스, 대상 체크와 해당 앱의 자체 방향 정책을 확인하세요.
이전 방향이 복원되지 않습니다
시스템 설정 변경 허용 상태와 다른 회전 제어 앱의 개입 여부를 확인하세요.
05

데이터와 보안

  • 선택한 앱 목록은 로컬에 저장합니다. 서버 계정이나 인터넷 연결이 필요하지 않습니다.
  • 더 이상 사용하지 않으면 Android 설정에서 관련 권한·서비스도 해제하세요.
06

알아두실 제한사항

  • 일부 제조사 펌웨어·게임·카메라·멀티윈도우·대화면 정책은 방향 요청을 무시할 수 있습니다.
  • 접근성 서비스와 설정 변경 권한은 사용자가 직접 관리해야 하며 강제 종료 시 유지되지 않을 수 있습니다.
07

소스 실행·검증

아래는 문서용 명령 예시입니다. 실제 실행에는 해당 README의 개발 환경·권한·의존성 준비가 필요합니다. 프로젝트 루트에서 사용하며 이 문서를 열기만 해서는 실행되지 않습니다.

.\gradlew.bat testDebugUnitTest lintDebug assembleDebug

Android 프로젝트는 별도 안내가 없으면 JDK 17·Android SDK 설정이 필요합니다. 문서 변경 때문에 앱을 새로 빌드하거나 실제 운영 데이터를 조작하지 않았습니다.
